Hermes Trader V3 — 全链路交易系统架构

AI 驱动 · 7×24 自动交易 · 多模块分层流水线

📋 模块说明

📊 Market Data

OKX WebSocket 实时行情，订阅 ticker/trades/books/funding/OI 频道。每 30 秒更新一次技术指标缓存。

📰 News Pipeline

8 源异步采集 (OKX/Binance/Bybit/CoinDesk/CoinTelegraph/TheBlock/Decrypt/Blockworks)。事件分类 (12种)、去重合并、评分筛选，仅 36+ 分新闻送 LLM。

⚡ Priority Scheduler

事件驱动调度器。Hack=100、Exchange=95、ETF=90、ATR=40 等优先级。支持去重、过期 (TTL)、合并。高优事件打断低优。

🏥 Health Manager

监控 DeepSeek/OKX/DB/WS。健康分 0~100：≥80 正常，≥60 禁止开仓，≥40 仅平仓，<40 停止。拥有最高暂停权。

🔁 State Machine

状态: INIT→NORMAL→READY→OPENING→LONG/SHORT→EXITING。连续亏损≥3 自动 COOLDOWN 30 分钟。LLM 不可修改状态。

📊 Portfolio Manager

总敞口/杠杆/相关性控制。同方向≤60%，相关币种≤80%，总杠杆≤5x。can_add_position() 返回 allowed+原因。

🧠 AI Gateway

统一 LLM 入口。Model Routing、重试、超时、缓存、Prompt 版本/Hash、Token 用量&成本。支持 DeepSeek 等。

⚠️ Signal Validator

最高否决权。EMA20/60 排列、RSI 边界 (LONG≤75, SHORT≥25)、ATR 过滤器 (×3)、新闻方向冲突降权。纯程序规则。

🛡️ Risk Engine

输出 TradePermission。仓位限制、日亏损上限、连续亏损、单笔亏损、R/R 比、资金费率、重大新闻暂停、波动率过滤。

⚙️ Execution Engine

指数退避重试 (1/2/4/8/16s)、断路器 (5次熔断5分钟)、幂等控制。只消费 ExecutionPermission，不直接读取 LLM。

💾 Replay & Memory

每次分析 (含 HOLD) 完整快照。Prompt/LLM/Validator/Risk/State 全部记录。Trade/Market/Failure Memory 分离。

🔌 外部推送

微信每小时状态推送 + 实时交易信号通知。Trade Session ID 绑定全部日志。

⚡ 交易流水线 (16 步)

Market Data → Indicators → News Pipeline → Priority Scheduler → Health Manager → State Machine → Portfolio Manager → AI Gateway → Strategy Planner → ⚠️ Signal Validator → Risk Engine → TradePermission → Execution Engine → StateMachine Update → Replay → Memory → 推送通知
