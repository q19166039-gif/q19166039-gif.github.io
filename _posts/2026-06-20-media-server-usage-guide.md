## 加电影（Radarr）

1. 浏览器打开 `http://192.168.1.165:7878`
2. 点顶部 **电影 → 添加新电影**
3. 搜索框输入电影名（中文英文都行）
4. 找到后点电影封面 → 确认片名、年份
5. 点 **添加电影**，搞定，等着就行

**Radarr 会用你配置的那个 Release Profile 来识别你要的是 REMUX / 1080p / 4K，会自动挑质量最好的。** 选片时注意 Release Profile 状态（在搜索框底部），确保是和你想下的品质一致。

整个流程：Radarr 自动通过 Prowlarr 搜索种子 → 扔给 qBittorrent 下载 → 完成后自动重命名整理到 `/media/movies/` → Jellyfin 自动入库。

---

## 加剧集（Sonarr）

1. 浏览器打开 `http://192.168.1.165:8989`
2. 点顶部 **系列 → 添加新系列**
3. 搜索剧名
4. 选好剧集，点 **添加系列**
5. 可以选要追的季数（默认全部）
6. 搞定

Sonarr 会自动追更，每出一集新的一集就自动下载。已完结的剧集一次性全下。

---

## 配字幕（Bazarr）

Bazarr 会自动给电影和剧集找中文字幕，不需要手动操作。

如果想手动查状态：
`http://192.168.1.165:6767`

- **电影** → 已下载字幕的清单，可以手动搜索/强制下载
- **剧集** → 同上，按系列查看
- **历史** → 看最近字幕下载记录

> 字幕源已配好，不用管配置。

## 播放（Jellyfin）

### 浏览器/手机
1. 打开 `http://192.168.1.165:8096`，登录（admin / admin123）
2. 点 **电影** 或 **剧集** 就能看到已入库的内容
3. 点封面直接播放

### 电视（推荐方式）
**雷鸟电视（TCL）已装 Jellyfin TV 客户端**，直接打开 App 即可。首次登录输入服务器地址 `http://192.168.1.165:8096` 和账号密码。

> 电视端解码能力比浏览器强，4K 片源建议电视上看。

### 外网播放
Jellyfin 走内网直接访问。外网播放需要通过代理/VPN回家，目前未配置外网穿透。

## 存储结构

```
/media/（挂载独立硬盘）
├── downloads/    ← 下载临时目录（不用管，qB 自动管理）
├── movies/       ← 电影库（Jellyfin + Radarr 共同维护）
└── tv/           ← 剧集库（Jellyfin + Sonarr 共同维护）
```

## 下载进度查看

### 正在下载
打开 `http://192.168.1.165:8080` 看 qBittorrent
- 能看到每个任务的速度、进度、做种情况
- 下完自动移到对应目录并继续做种

### 队列状态
Radarr/Sonarr → **活动 → 队列**，能看到：
- **正在下载**：种子已扔给 qB，正在下
- **等待中**：可用种还没找到，自动重试中

## 如果搜不到资源

Prowlarr 配了 7 个公开索引器（1337x, The Pirate Bay, YTS, LimeTorrents, TorrentGalaxy, EZTV, Nyaa），覆盖大部分主流资源。

如果某个冷门资源搜不到，手动方案：
1. 自己去搜种子（.torrent 文件或磁力链接）
2. 在 **qBittorrent** `http://192.168.1.165:8080` 里添加下载
3. 下完后手动把文件移到 `/media/movies/` 或 `/media/tv/` 对应目录
4. 在 Jellyfin 控制台 → 媒体库 → 扫描所有媒体库

## 常见问题

### 播放卡顿/转码
- **优先用电视端 Jellyfin App**，硬件解码支持最好
- 浏览器播放 4K 片源可能需要转码，转码时注意服务器负载
- 确认网络是千兆直连（AC2100 ↔ PVE ↔ CT101 全是千兆）

### 字幕不显示
检查 `http://192.168.1.165:6767` 里该片字幕状态，可以手动强制搜索。Jellyfin 播放时右下角选择字幕。

### 没有自动下载
- Radarr/Sonarr 搜到了吗？
- qBittorrent 里有种子在等做种吗？
- 检查 Radarr/Sonarr → 系统 → 事件日志
